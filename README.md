# 🏋️‍♂️ ระบบจองฟิตเนสอัจฉริยะ (Smart Fitness Booking System)

ระบบ Web Application สำหรับประมวลผลภาษาธรรมชาติ (NLP) เพื่อคัดแยกหมวดหมู่ความต้องการจองบริการฟิตเนสของลูกค้าจากข้อความภาษามนุษย์

## 🎯 วัตถุประสงค์และแนวคิด
ช่วยให้ลูกค้าสามารถพิมพ์ความต้องการจองคลาส นัดเทรนเนอร์ หรือสอบถามข้อมูลเข้ามาในรูปแบบภาษาพูดได้อย่างเป็นธรรมชาติ ระบบจะนำข้อความมาผ่านกระบวนการ NLP เพื่อวิเคราะห์เจตนา (Intent Classification) และจัดหมวดหมู่คำขอให้อัตโนมัติ

## 🛠️ เทคนิค NLP ที่นำมาประยุกต์ใช้
1. **Regex & Cleansing:** ทำความสะอาดข้อความ ลบอักขระพิเศษและช่องว่างส่วนเกิน
2. **Tokenization:** ตัดคำภาษาไทยโดยใช้ไลบรารี `PyThaiNLP` (Engine: `newmm`)
3. **Topic Identification & Matching:** ใช้โมเดล **BERT** (`paraphrase-multilingual-MiniLM-L12-v2`) เปลี่ยนข้อความให้เป็น Vector ความหมายเชิงบริบท และคำนวณ Cosine Similarity เพื่อจับคู่กับหมวดหมู่ในระบบ

## 📁 โครงสร้างไฟล์ใน Repository
- `app.py`: ไฟล์สคริปต์หลักของ Streamlit Web Application
- `dataset.csv`: ชุดข้อมูลข้อความจองฟิตเนสจำลอง 30 ตัวอย่าง (6 หมวดหมู่)
- `requirements.txt`: รายชื่อไลบรารีภาษา Python ที่ใช้ในระบบ
- `README.md`: เอกสารอธิบายโครงการและการใช้งาน
